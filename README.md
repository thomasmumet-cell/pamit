# PAMIT

**Pengajuan dan Monitoring Izin Terpadu**: aplikasi lapor izin guru dan karyawan.

Alamat: https://thomasmumet-cell.github.io/pamit/

Repo ini hanya berisi tampilan. Data tersimpan di Google Sheets sekolah, dan kode server
disimpan di repo privat `kode-apps-script` (folder `pamit/`).

## Pasang di HP

Buka alamat di atas dengan Chrome → ketuk ⋮ → **Tambahkan ke layar utama**.
